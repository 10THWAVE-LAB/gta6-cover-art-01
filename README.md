Vice Cover Maker: turn your own photos into GTA-style multi-panel cover art. Drop in photos, pick a layout (grid, quad, duo or solo), grade it (sunset, neon or noir), add a bold title, and export a print-ready PNG at 1080×1080, 1080×1350 or 1920×1080 — all in the browser, no uploads.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
